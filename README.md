One funny line of wedding vows for a robot couple: a real vow — love in
sickness and in health, in low battery and in full charge — with the laugh
paying off in the last few words.

## Run it

```sh
python3 main.py
```

It writes the vow (127 characters, one line) to `/output/entry.txt`.
